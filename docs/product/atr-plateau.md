## 1. 产品目标与非目标

### 目标

- 用无量纲系数 `k` 统一不同股票、不同价格基数和不同波动率量级的网格密度研究。
- 以 `k × 日线 ATR(14)%` 定义网格步长，扫描 `k` 的完整曲线，寻找连续、平坦、可解释的参数高原。
- 使用 5 分钟 K 线执行“0 或 1”阶跃触线撮合，统计有效闭环次数 `n(k)` 和扣除摩擦后的归一化净收益率。
- 剔除左右相邻点断崖式下跌的“参数孤岛”，降低单点过拟合。
- 在参数高原内选择中心偏左的 `k*`，兼顾未来鲁棒性和阈值截断效应。
- 将 `k*` 还原为当前 ATR% 下的实盘步长，并输出整数关口抢跑修正和拐点触发条件单参数。
- 在页面中以 k 为横轴展示倒 U 型双轴图、禁区、先验带、高原带、孤岛和步长转换卡片。

### 非目标

- 不提供买卖建议，不保证未来收益。
- 不替代已有的 6 个月滚动样本外验证和最终锁定盲测。
- 不建模完整盘口、逐笔成交、涨跌停、停牌、滑点和成交量冲击。
- 不在浏览器中计算回测、筛选或评分。
- 不把单格归一化研究的 `q = M / price` 直接当作实盘股数；实盘仍需按一手取整和资金约束另行计算。

## 2. 用户与使用场景

目标用户是进行个人网格策略研究的用户。

典型场景：

- 用户想比较同一只股票在不同波动率阶段的网格密度，而不是只看绝对价格步长。
- 用户希望确认某个 k 值附近是否存在连续高原，避免选中历史回测的单一尖峰。
- 用户想观察低 k 区的手续费磨损禁区、0.65–0.80 × ATR% 理论先验带和实测高原是否重合。
- 用户已经得到 `k*`，希望快速还原为当前 ATR% 下的百分比步长、绝对价格格距和抢跑修正后的执行步长。
- 用户想同时看到“基础步长 + 回落卖出/反弹买入”的动态拉伸参数。

## 3. 输入参数与默认值

| 参数 | 默认值 | 说明 |
|---|---|---|
| `code` | 必填 | 股票代码 |
| `grid_amount` | 10000 | 单格固定投入金额 M（元），用于归一化和摩擦计算 |
| `max_positions` | 8 | 同时持有的最大网格槽位数，网格资金 = M × 该值 |
| `fee` | 0.025 | 单边佣金 % |
| `min_fee` | 5 | 单笔最低佣金（元） |
| `spread_pct` | 0.05 | 买卖价差代理 % |
| `friction_pct` | 空 | 可直接指定双边摩擦 C%；为空时由佣金、最低佣金、印花税和价差推导 |
| `k_start` | 0.20 | k 扫描起点 |
| `k_end` | 2.50 | k 扫描终点 |
| `k_step` | 0.05 | k 扫描步长 |
| `mode` | dynamic | `dynamic`：每日步长随前一日 ATR 缩放；`static_mean`：使用历史扩展日均 ATR% 的固定百分比步长 |
| `atr_period` | 14 | 日线 ATR 周期 |
| `plateau_window` | 5 | 高原滑动窗口点数 W_k，约 0.20 个 k 跨度 |
| `plateau_stability_penalty` | 0.5 | 高原评分 `mean - penalty × stdev` 中的方差惩罚系数 |
| `plateau_center_left_ratio` | 0.35 | 在高原窗口内选取中心偏左位置的比率 |
| `island_drop_ratio` | 0.25 | 孤岛判定：左右相邻点相对跌幅阈值 |
| `island_min_drop_pct` | 0.20 | 孤岛判定的最小绝对跌幅（百分点） |
| `front_run_thresholds` | `[1,2,3,5]` | 需要抢跑的整数百分比关口 |
| `front_run_band_pct` | 0.08 | 距离整数关口多近时触发修正 |
| `front_run_offset_pct` | 0.20 | 向下微调的百分点 |
| `pullback_sell_pct` | 0.30 | 拐点条件单的回落卖出幅度 |
| `rebound_buy_pct` | 0.30 | 拐点条件单的反弹买入幅度 |
| `history_days` | 500 | 拉取历史交易日数 |

默认 k 值：

```text
0.20, 0.25, 0.30, ..., 2.45, 2.50
```

共 47 个值。

## 5. 指标口径

### 5.1 摩擦成本

```text
fee_effective% = max(fee, min_fee / M × 100)
C% = 2 × fee_effective% + 印花税 0.05% + spread_pct
```

`C%` 是单次买入→卖出闭环的往返摩擦，按单格名义本金 M 的比例表示。若用户直接提供 `friction_pct`，则使用该值。

### 5.2 安全底线

```text
k_min_safe = 10 × C% / mean(ATR14%)
```

`k < k_min_safe` 的区域标记为高频刷单手续费磨损禁区。该区间仍绘制原始曲线，但不参与高原选择。

### 5.3 滚动阶梯网格与阶跃触线撮合

- 每个交易日以前一交易日收盘价作为锚点，重新布置一组买单。
- 买单档位为 `anchor - j × step`，`j = 1..max_positions`。
- 每个档位对应一个独立的单格名义本金 M；最多同时持有 `max_positions` 个槽位。
- 空仓槽位在价格最低价触及格线时买入；差一分钱未触及则不成交，对应“0 或 1”阶跃触发。
- 每个持仓槽位的目标卖价为买入价加一个步长；最高价触及目标价才卖出。
- 跳空时按格线价成交，不使用开盘价的有利跳空改善，保持归一化研究的一致性。
- 当日买入的仓位当日不能卖出（T+1）。
- 槽位卖出后可以再次使用，但同一交易日同一个档位只成交一次。
- 每日重新锚定是为了避免单边趋势把网格“冻结”在一次卖出之后；没有重新锚定时，`n(k)` 可能长期恒为 1，净收益曲线会退化成随 k 线性增长。

### 5.4 归一化收益

```text
单次闭环毛利% = (卖出价 / 买入价 - 1) × 100
单次闭环净利% = 单次闭环毛利% - C%
net_return_pct = Σ 单次闭环净利%
```

`net_return_pct` 是**单格名义本金 M**上的累计已实现净收益率，`loops` 即 `n(k)`。`annualized_net_return_pct` 按 243 个交易日年化。

同时输出：

- `capital_return_pct`：`net_return_pct / max_positions`，即占网格总资金 `M × max_positions` 的收益率。
- `used_capital_return_pct`：`net_return_pct / max_positions_used`，按历史最大占用槽位归一化。
- `capital_utilization_pct`：历史最大占用槽位 / 最大槽位。
- `gross_return_pct`：未扣摩擦的闭环毛利。
- `friction_paid_pct`：`loops × C%`。
- `open_position_pnl_pct`：期末未平仓浮盈亏，不计入高原选择。
- `open_position_count`：期末未平仓槽位数。
- `total_return_pct`：已实现净收益 + 期末浮盈亏。
- `max_open_loss_pct`：持仓期间最大合计浮亏。
- `risk_adjusted_return_pct`：`net_return_pct + min(0, open_position_pnl_pct)`，用于观察期末浮亏对收益的保守扣减；高原选择仍使用已实现净收益。

### 5.5 参数孤岛

对每个非禁区内部点，计算：

```text
left_drop  = value[i] - value[i-1]
right_drop = value[i] - value[i+1]
threshold  = max(island_min_drop_pct, |value[i]| × island_drop_ratio)
```

当 `value[i] > 0` 且 `left_drop >= threshold` 且 `right_drop >= threshold` 时，标记为孤岛。孤岛不参与高原选择。

### 5.6 参数高原

在非禁区、非孤岛的连续窗口中，寻找长度为 W_k 的窗口：

```text
plateau_score = mean(net_return_pct) - stability_penalty × stdev(net_return_pct)
```

选择 `plateau_score` 最高的窗口；平局时选择标准差更低、k 更小的窗口。若可用连续点不足 W_k，则自动缩短窗口并在结果中标记 `window_adjusted`。

`k*` 取高原窗口内中心偏左的位置：

```text
offset = round((W_k - 1) × plateau_center_left_ratio)
index  = k_left_index + offset
```

默认 `plateau_center_left_ratio = 0.35`。中心偏左用于规避“差一分钱未触及 ATR 边缘”的阈值截断效应，同时避免落在高原最左边缘。

### 5.7 理论先验交叉验证

```text
prior_band = [0.65, 0.80] × ATR%
prior_anchor = 0.70 × ATR%
overlap = [max(k_left, 0.65), min(k_right, 0.80)]
```

输出是否重合、重合宽度、重合比例、是否包含 0.70，以及 `k*` 位于先验区间内/下方/上方。未重合时给出风险提示。

### 5.8 实盘步长还原与抢跑修正

```text
d_raw% = k* × ATR14_current%
d_raw_abs = latest_price × d_raw% / 100
```

若 `d_raw%` 距离 1.0 / 2.0 / 3.0 / 5.0 等整数关口不超过 `front_run_band_pct`，则向下微调 `front_run_offset_pct`：

```text
d_exec% = d_raw% - front_run_offset_pct
k_exec = d_exec% / ATR14_current%
```

如果微调会跌破 `k_min_safe` 对应的安全步长，则保持原步长并给出警告。

### 5.9 拐点触发参数

```text
base_step_pct = d_exec%
stretch_step_pct = d_exec% + max(pullback_sell_pct, rebound_buy_pct)
buy_trigger_price = latest_price × (1 - d_exec% / 100)
sell_trigger_price = latest_price × (1 + d_exec% / 100)
```

窄幅震荡使用基础步长保留成交频次；趋势段由回落卖出 / 反弹买入条件单拉伸有效步长。

## 6. 数据源、缓存与数据快照

- 5 分钟 K 线和日线来自 BaoStock。
- 使用前复权，复用 `IntradayRepository` 和本地 SQLite 缓存。
- 默认缓存路径 `.cache/intraday.sqlite3`。
- 每次结果记录数据起止日期、bar 数量、日线数量、最新 ATR 和最新价格。
- ATR(14) 使用 Wilder 算法，包含跳空缺口。
- 为避免未来函数，交易日的步长只使用前一交易日及更早的 ATR。
- 静态均值模式使用扩展窗口的历史日均 ATR%，不使用包含未来数据的全样本均值。
- 最新 ATR 只用于“下一交易日”的实盘步长还原。

## 7. 验证方法论

### 7.1 样本内扫描

本模块是实验性的样本内参数高原扫描：

- 使用同一段历史 5 分钟数据生成整条 k 曲线。
- 不包含滚动样本外验证。
- 不包含最终锁定盲测。
- 结果必须与已有的 6 个月滚动 OOS 和最终盲测交叉参考。

### 7.2 无未来函数

- 交易日 t 的动态步长使用 t-1 及更早的日线 ATR。
- 交易日 t 的阶梯锚点使用 t-1 的日线收盘价。
- 静态均值模式使用 t-1 及更早的扩展均值。
- 实盘步长使用最新已收盘日线的 ATR，仅用于下一交易日。
- 高原选择使用整段样本内曲线，这是参数研究本身的性质，不作为样本外证据。

### 7.3 可重复性

- 相同 5 分钟数据、日线数据、参数和摩擦设置必须产生相同曲线。
- 不使用随机数。
- 单元测试覆盖阶跃触发、差一分钱不成交、T+1、滚动再锚定、多槽位、最大持仓、孤岛剔除、高原选择和抢跑修正。
- 回归测试覆盖“单边趋势后仍能重新挂单并产生多个闭环”，防止曲线退化为 `n(k)≈1` 的线性形态。
- 集成测试使用固定夹具，不访问真实网络。

## 9. 交互流程与状态

1. 用户输入股票代码和基础资金/费用参数。
2. 在“ATR 归一化参数高原（实验）”面板选择锚定模式、k 范围、单格资金、最大持仓槽位和高原窗口。
3. 点击“生成 ATR 归一化高原”。
4. 前端调用 `POST /api/plateau`，按钮进入禁用状态并显示计算提示。
5. 后端读取 5 分钟和日线缓存，缺失数据从 BaoStock 补拉。
6. 后端计算 ATR 序列、k 曲线、孤岛、高原、先验重合和实盘步长。
7. 前端渲染双轴图、转换卡片、拐点参数、先验验证和明细表。
8. 失败时显示明确错误，不展示部分伪造结果。

## 10. 边界条件与已知限制

- 滚动阶梯网格是研究模型，不是完整实盘撮合；每日重锚是简化假设，真实网格通常按区间边界或手动校准重锚。
- 网格资金上限为 `M × max_positions`，但未建模逐格现金占用、最低佣金对单笔数量的取整和资金不足一手。
- 使用 `q = M / price` 的归一化数量，不做 A 股一手取整；实盘股数需另行计算。
- 未建模涨跌停、停牌、滑点、成交量和盘口冲击。
- 5 分钟数据可能有缺失 bar、半天市和停牌缺口。
- T+1 会显著降低同日回转次数，尤其是高波动日。
- 期末未平仓浮亏不计入高原选择，只通过 `open_position_pnl_pct`、`max_open_loss_pct` 和诊断提示展示。
- 样本内参数高原存在过拟合风险，必须结合滚动 OOS 和最终盲测。
- 整数关口抢跑修正是经验规则，不是订单簿事实。
- 理论先验 `0.65–0.80 × ATR%` 是参考带，不是硬约束。
- 当所有 k 都低于安全底线时，不输出实盘步长。
- 当找不到连续高原时，不输出 `k*`，只保留曲线和原因。
- 当原始最优落在手续费禁区时，只输出合规高原并给出提示；不会为了得到正收益而绕过安全底线。

## 11. 性能预算与失败处理

- 默认 47 个 k 值，每个 k 单次遍历 5 分钟 bar，复杂度约为 `O(k_count × bar_count)`。
- 使用内存分组和单次 ATR 计算，避免重复拉取数据。
- 优先使用本地 SQLite 缓存。
- 单只股票失败返回明确错误，不影响其他请求。
- 计算过程中不允许无上限并发请求 BaoStock。
- 前端按钮在请求期间禁用，避免重复提交。

## 12. 验收标准

- 默认 k 从 0.20 到 2.50，步长 0.05，共 47 个值。
- 曲线包含每个 k 的净收益率、占网格资金收益、闭环次数、最大持仓、禁区标记、孤岛标记和高原标记。
- `k_min_safe = 10 × C% / mean(ATR14%)`。
- 0/1 阶跃触线：差一分钱未触及不成交。
- 每个交易日以前一交易日收盘价重新锚定阶梯，单边趋势后仍能重新挂单。
- 最多同时持有 `max_positions` 个槽位，超出后不再买入。
- 买入当日不能卖出（T+1）。
- 孤岛点不参与高原选择。
- 高原窗口连续，`k*` 位于窗口内且中心偏左。
- 输出与 `0.65–0.80 × ATR%` 先验区间的重合关系。
- 输出 `k* × ATR% = d_raw%` 与抢跑修正后的 `d_exec%`、`k_exec`、绝对格距。
- 前端双轴图包含禁区、先验带、高原带、星标和孤岛框。
- 产品文档、API 文档、方法论文档和 CHANGELOG 同提交更新。
- `make ci` 和隐私扫描通过。
