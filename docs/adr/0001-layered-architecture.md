# ADR 0001: 分层架构

## 状态

已采纳。

## 背景

早期 `app.py` 同时承担行情、指标、网格、回测、风控、API 和页面返回，字段靠 dict 隐式约定，难以测试和演进。

## 决策

采用分层结构：

- `data`：外部行情 I/O 与缓存；
- `indicators` / `grid` / `backtest` / `risk`：纯计算；
- `services`：流程编排；
- `api`：HTTP 契约；
- `web`：展示与交互。

顶层 `app.py` 只保留兼容入口，systemd 启动方式不变。

## 影响

- 纯计算可离线测试；
- 新增功能有明确落点；
- 轻微增加目录和导入复杂度，但换来了可维护性。
