# 方法论文档

本文把 `file.md` 中的网格交易认知映射到代码，明确公式、假设和限制。

## 1. 空间结构

- 中轴：`indicators/axis.py` 使用 60 日收盘中位数作为推荐中轴。
- 区间：`grid/designer.py` 使用近 60 日高低点，保留 2% 安全边界；区间过窄时围绕中轴扩展到约 ±8%。
- 间距：`grid/spacing.py` 采用等比档位，价格序列为 `P(n) = lower × (1 + gap)^n`。

## 2. 波动率与间距

- 日波动率：近 120 日收益率标准差，年化使用 `σ_daily × √243`。
- ATR：Wilder ATR(14)，包含跳空缺口。
- 布林带宽：`(upper - lower) / mid = 4 × σ / mid`。
- 带宽历史分位：当前带宽在可用历史带宽中的百分位。
- TTM Squeeze：布林带上下轨完全收缩进肯特纳通道内部。
- Vol of Vol：滚动 20 日波动率的标准差，再年化。

间距下限：

```text
min_gap = spread% + round_trip_cost% + 0.15% buffer
```

主网格间距：

```text
gap = max(1.2 × min_gap, 0.70 × ATR%, 1.0 × σ_daily) × gap_scale
gap = min(gap, 8%)
gap = max(gap, min_gap)
```

辅助网格使用 `1.0 × min_gap`、`0.55 × ATR%`、`0.7 × σ_daily`，上限 4%。

资金不足一手时，按“最多可买档位数”反推所需间距，自动拉宽，并在结果中标记 `capital_constrained`。

## 3. 收益与风险

- 每格闭环毛利近似为 `q × d`。
- 单边下跌时，第 `i` 格浮亏累加，总浮亏近似与价格偏离度平方相关。
- 破网止损：价格跌破 `lower × (1 - stop_loss%)` 后清仓并停止交易。
- T+1：当日买入的仓位当日不可卖出。
- 现金约束：买入必须由可用现金支付，不足时跳过该格买单。
- 费用：双边佣金（含最低佣金）+ 卖出印花税 0.05%。

## 4. 回测路径

日线 OHLC 无法还原真实分时路径，采用保守近似：

```text
前收 → 开盘 → 日内低/高 → 收盘
```

- 阳线：开盘 → 低 → 高 → 收盘；
- 阴线：开盘 → 高 → 低 → 收盘；
- 处理隔夜跳空；
- 开盘时已持有且目标卖价低于开盘价的仓位，按开盘价卖出；
- 止损优先于新建仓。

## 5. 避免未来函数

- 当前推荐参数使用最新数据。
- 回测参数只使用回测窗口之前的数据校准。
- Walk-forward：

```text
[校准窗口][测试窗口]
        [校准窗口][测试窗口]
                [校准窗口][测试窗口]
```

每个窗口内，网格只由校准段生成，收益只来自测试段。

## 6. 参数高原

参数扫描输出：

- `mean_return_pct`：样本外平均收益；
- `worst_return_pct`：最差窗口；
- `compounded_return_pct`：样本外复利；
- `max_drawdown_pct`：最大单窗口回撤；
- `stop_count`：止损次数；
- `plateau_score = mean_return_pct - stdev_return_pct`。

选择高原时优先看相邻参数是否同样稳定，而不是单点最高收益。

`scripts/sweep.py` 会额外生成 HTML 热力图，横轴为 `gap_scale`，纵轴为 `stop_loss`，单元格为 `init_position` 维度上的均值。

## 7. 已知限制

- 日线级回测无法模拟 09:31 流动性真空和盘口冲击。
- 历史买卖价差使用固定代理或当前盘口，不是逐日真实价差。
- 未建模涨跌停、停牌、滑点和成交量约束。
- 参数扫描仍可能过拟合，需要更多样本外区间和滚动验证。
